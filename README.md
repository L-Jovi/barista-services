# Exercise Services

Backend exercises, small service examples, and notes on connecting services. Each directory has its own dependencies and setup; the repository is not one application to start from the root.

## Find an example

| Directory | What it contains |
| --- | --- |
| [django-demo-server](django-demo-server/README.md) | Django exercises organized around chapters of a book |
| [graphql/typescript-apollo-server](graphql/typescript-apollo-server/README.md) | The HowToGraphQL tutorial using TypeScript, Apollo Server, Nexus, and Prisma |
| [hotfix-server](hotfix-server/README.md) | A Python server exercise for iOS JavaScript patches and SQL-injection/XSS demonstrations |
| [isomorphic/react-ssr-simple-server](isomorphic/react-ssr-simple-server/README.md) | React server/client rendering with backend routes and hot module replacement |
| [node-es6-simple-server](node-es6-simple-server/README.md) | A Node.js server example with ES6 support |
| [node-oauth-server](node-oauth-server/README.md) | An imported GitHub OAuth 2.0 login demonstration, with its original attribution |
| [node-red-server](node-red-server/README.md) | Personal practice notes on Node-RED flows and the AISee/Nodinx service context |
| [scrapy-demo](scrapy-demo/README.md) | Scrapy crawler exercises |

Read the selected directory's README before using its commands. These materials describe their own examples and historical environments; this index does not establish that they run on a current machine.
